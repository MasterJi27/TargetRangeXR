## Gameplay

- **Gun pickup:** XRGrabInteractable for XR; exclusive desktop-held state for the additional keyboard mode.
- **Trigger/click fires bullet:** Pistol routes held-weapon fire to BulletPool; Bullet sweeps physical hit detection along its frame movement.
- **Shot feedback:** muzzle particles, light, slide recoil and audio in Pistol/FeedbackController.
- **Multiple static/moving targets:** five near, three moving, two far.
- **Physical hit response:** Target becomes dynamic and receives AddForceAtPosition, falls, vanishes and respawns. Already-knocked targets do not score twice.
- **Target destruction:** represented as knockdown and disappearance followed by respawn, not permanent Destroy of the runtime object. This interpretation keeps the range populated through the round.
- **Score and 60-second countdown:** GameManager, CountdownTimer, ScoreTally; displayed on desktop HUD or XR boards.
- **End freeze, final score, Restart/Exit:** GameManager sets timeScale to zero; ResultsView exposes both actions and uses unscaled UI fading. Desktop results have keyboard shortcuts and an overlay canvas.
- **Replay:** targets, gun, active projectiles, score and time reset; next round waits for pickup.

Unity PlayMode tests cover desktop pickup, target hits, physics and replay; the XR right-controller test passes using programmatic selection. Manual verification remains pending.
